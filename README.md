# Burble — Concordia

Water AI Hackathon 2026 sunumu. Three.js ile tek dünyada 10 sahne ve sahne 7'de canlı prototip.

Canlı: https://burble-sunum.vercel.app

## Çalıştırma

```
npm install
npm run dev
```

## Kontroller

- → / boşluk: ileri · ←: geri · F: tam ekran · R: prototipi sıfırla
- `#7` gibi bir adresle doğrudan sahneye gidilir
- Dokunmatik: dokun → ileri, sol kenara dokun → geri, kaydırma

`main` dalına yapılan her push Vercel'de otomatik yayına alınır.
